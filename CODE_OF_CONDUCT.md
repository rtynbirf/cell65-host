# Кодекс поведения

Правило одно: относись к другим участникам как к взрослым инженерам.

- Критикуй код, а не человека. Обосновывай: факт, источник, тест.
- Политика, идеология и «зачем это вообще» — вне репозитория; здесь только техника.
- Уязвимости — по схеме из [SECURITY.md](SECURITY.md), а не в публичных issues.
- Публикация чужих секретов или персональных данных — мгновенный бан без обсуждения.

Этот документ — урезанный Contributor Covenant (v2.1), адаптированный под
инженерный характер проекта.
