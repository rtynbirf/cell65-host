# CODESPACE-УЗЕЛ — бесплатная личная прокси-машина на GitHub Codespaces

Линия «узел без VPS»: кодспейс GitHub — это Ubuntu-машина (2 ядра / 8 ГБ ОЗУ /
32 ГБ SSD) в облаке GitHub. Бесплатно: 120 core-часов в месяц (= 60 часов
на машине с 2 ядрами) и 15 ГБ-мес хранилища. Аккаунт создаётся по email —
телефон и банковская карта не нужны.

Комплект (вся папка скачивается и работает как есть):

| Файл | Роль |
|---|---|
| `codespace-bootstrap.sh` | Инициализация кодспейса: ставит gost 2.12.0 (HTTP :18080 + SOCKS5 :18081), самотест обоих портов 204/204. Идемпотентен — повторный запуск безопасен |
| `65-codespace.ps1` | Супервизор на Windows-машине (PowerShell 5.1): ставит gh CLI, логинит, создаёт репо+кодспейс, заливает bootstrap, держит SSH-туннель, сторожит разрывы; `-Stop` — останов |
| `START_CODESPACE.bat` | Запуск супервизора двойным кликом |
| `STOP_CODESPACE.bat` | Останов и гашение кодспейса двойным кликом |

## Схема работы

У кодспейса **нет входящего белого IP** — напрямую `socks5://ip:порт` снаружи
не прокинешь. Клиент подключается SSH-туннелем через gh CLI (ключи создаются
автоматически, паролей нет):

```
[Chrome + «Антицензор» MV3]
        │  HTTP 127.0.0.1:18080 (как обычно)
[gost на твоей машине]
        │  socks5 → 127.0.0.1:19081
[SSH-туннель gh cs ssh -N -L 19080:...:18080 -L 19081:...:18081]
        │
[Codespace: gost HTTP :18080 / SOCKS5 :18081]
        │
     интернет
```

Для CELL-65 меняется только апстрим локального gost:

```
gost.exe -L=:18080 -F=socks5://127.0.0.1:19081
```

Расширение не трогается — оно по-прежнему ходит на `127.0.0.1:18080`.
Прямо в расширении можно указать апстрим `socks5://127.0.0.1:19081` без
локального gost вовсе.

## Быстрый старт (5 минут)

1. Положить PAT (classic, галочки `repo` + `codespace`) в файл
   `%USERPROFILE%\cell65\gh_token.txt` — одна строка, сам токен.
   Альтернатива: не класть ничего — первый запуск откроет браузер для
   одноразового входа gh.
2. Запустить `START_CODESPACE.bat`. Первый прогон: поставит gh (winget),
   создаст репо+кодспейс (1–3 мин), зальёт bootstrap, поднимет туннель
   и останется сторожить.
3. Апстрим в расширении: `socks5://127.0.0.1:19081`.
4. Останов (погасить кодспейс, не жечь часы): `STOP_CODESPACE.bat`.

## Лимиты и ретеншен (верифицировано — журнал в `docs/SOURCES.md`, №16–18)

- 120 core-часов/мес ≈ 2 часа в день на машине 2 ядра. Расход:
  `github.com/settings/billing` → Codespaces.
- Кодспейс живёт, пока запущен супервизор; после `-Stop` уснёт и через
  ~30 минут idle перестанет тратить часы (максимальная жизнь одной
  сессии — 12 часов).
- **Ретеншен 30 дней (дефолт):** кодспейс без пробуждения 30 дней подряд
  GitHub удаляет автоматически. Репозиторий остаётся — это НЕ поломка:
  `START_CODESPACE.bat` сам создаст свежий кодспейс и зальёт gost заново
  (2–3 минуты). Работаете реже раза в месяц — запустите батник на пару
  минут до истечения срока, счётчик спячки обнулится.

## Правила использования (честно)

Codespaces позиционируется как среда разработки. Личный мелкий прокси для
себя — массовая практика, но формально серая зона. Гигиена: не раздавать
доступ никому, не гонять торренты, не майнить, трафик только личный.
Публичный прокси или перепродажа = бан. Трюк с GitHub Actions-перезапуском
по 6 часов — прямо против Acceptable Use Policies, в проекте не используется.

## Интеграция с «Антицензор» MV3

Узел — пиновый: известный адрес, живой по определению, максимальная
репутация. Селектор Cell'ов держит пин первым и уходит в общий пул,
только если пин умер.

## Troubleshoot

- Нет winget (старая Windows): скачать gh MSI вручную —
  `https://github.com/cli/cli/releases` (`gh_*_windows_amd64.msi`),
  поставить, запустить скрипт снова.
- Скрипт открыл браузер для входа — норма, один раз.
- Порты 19080/19081 заняты: `.\65-codespace.ps1 -LocalHttp 29080 -LocalSocks 29081`
- Провайдер режет SSH до GitHub: переход на схему с Tailscale — прямой
  socks5 на `100.x.y.z` без туннеля.
- Логи: `%USERPROFILE%\cell65\codespace-tunnel.log` (супервизор),
  `~/c65/gost.log` (внутри кодспейса).

## Этап 2 (опционально)

Tailscale на машине и в кодспейсе: стабильный адрес `100.x.y.z`, живой
socks5 без SSH-туннеля, ощущение настоящего VPS.
