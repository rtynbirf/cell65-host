# СУВЕРЕННЫЙ УЗЕЛ — коробка «настроил и забыл»

Один клиент (sing-box) + один сервер (sing-box) + один файл правды (node.env).
Три независимых транспорта с автопереключением. RU-сети идут напрямую, остальное — через лестницу.
Никаких Debian у тебя дома, никаких россыпей приложений, никаких ручных переключений.

---

## Карта пакета

```
sovereign-node/
├── node.env                          ← ЕДИНСТВЕННОЕ место, которое ты правишь
├── keys.txt                          ← резервная копия криптографии (убери офлайн)
├── windows/
│   ├── install-sovereign-node.ps1    ← главный скрипт Windows (служит и апдейтом конфига)
│   ├── provision-edge.ps1            ← включение КРАЯ (домен → зона → DNS → SSL)
│   └── uninstall.ps1                 ← полное снятие
├── server/
│   └── install-server.sh             ← единственный скрипт VPS
├── server.env                        ← серверная половина правды (копируется на VPS)
└── configs/                          ← примеры конфигов (для чтения; рабочие рендерятся скриптами)
```

## ШАГ 0 — Точка выхода (VPS)

Арендуй VPS за пределами РФ (Нидерланды, Финляндия, Германия, Швеция —юрисдикция без экстрадиции трафика в РФ):
- KVM-виртуализация, Ubuntu 22.04/24.04, ≥1 ГБ RAM, ≥1 ТБ трафика/мес, цена $3–6/мес
- Оплата — картой иностранного банка или крипто (Российские хостинги НЕ подходят — это surrender)
- После создания хостинга у тебя есть IP — впиши его в `node.env` → `VPS_IP=`

## ШАГ 0-СЕМЕЙНЫЙ — дети за границей (лучший мандат)

У детей карты работают, хостеры не задают вопросов, юрисдикция своя. Каждый ребёнок = отдельная ступень лестницы. Двое детей в разных странах = лестница в два пролёта.

### Путь А: дети арендуют VPS (30 минут, €4–6/мес)

Куда идти (платят своей локальной картой):
| Хостер | Страна/локации | Цена | Почему |
|---|---|---|---|
| **Hetzner** | Германия, Финляндия | ~€4.5 | лучший цена/качество, 20 ТБ трафика, чистые IP |
| Netcup | Германия | ~€3.5 | дёшево, стабильно |
| OVH | Франция, Польша | ~€4–5 | много локаций |
| Vultr / DigitalOcean | по миру | ~$6 | просто и быстро |
| Njalla, 1984.hosting, FlokiNET | Швеция/Исландия/Румыния | €5–8 | приватные, без паспорта, крипта |

ВАЖНО: избегать «русских» зарубежных хостеров (Aeza, VDSina и т.п.) — их подсети ТСПУ знает в лицо и душит в первую очередь. Нужны хостеры, которыми пользуются местные.

Параметры сервера: **Ubuntu 24.04, 1 vCPU / 2 ГБ RAM, локация DE/FI/NL/SE, трафик от 1 ТБ.**

Что дети делают (три действия):
1. Создают сервер, получают IP и root-доступ
2. Получают от вас два файла (`install-server.sh`, `server.env` — по защищённому каналу, там приватный ключ) и запускают:
   ```bash
   scp install-server.sh server.env root@IP_СЕРВЕРА:/root/
   ssh root@IP_СЕРВЕРА "bash install-server.sh"
   ```
3. Проверяют, что служба зелёная (`systemctl status sovereign-node`), и **присылают вам обратно только IP**.

Если у хостера есть внешний фаервол (у Hetzner — Cloud Firewall): открыть TCP 443, TCP 8443, UDP 443 — или выключить его вовсе.

Всё. Больше от детей ничего не нужно — ключи уже в вашем node.env, IP вставляете в `VPS_IP=` и запускаете установщик.

### Путь Б: узел живёт у детей дома (бесплатно, самый чистый IP)

Домашний IP провайдера за границей — идеальная маскировка: за ним живут люди, его не блокируют.
Что детям надо сделать у себя:
1. Выделить машину 24/7 (старый ноутбук, мини-ПК): Ubuntu Server 24.04
2. Запустить те же `install-server.sh` + `server.env` на ней
3. В роутере: закрепить IP за машиной (DHCP reservation) и пробросить порты TCP 443, TCP 8443, UDP 443 на неё
4. Если IP динамический — поставить DDNS-контракт (уже в пакете):
   ```bash
   sudo cp ddns-update.sh ddns.env /opt/sovereign-node/
   sudo chmod +x /opt/sovereign-node/ddns-update.sh
   (crontab -l 2>/dev/null; echo "*/5 * * * * /opt/sovereign-node/ddns-update.sh >> /var/log/ddns.log 2>&1") | crontab -
   ```
   Раз в 5 минут машина сама обновляет DNS через ваш CF-токен. В node.env тогда пишете `VPS_IP=direct.ВАШДОМЕН` вместо числа — и всё живёт при любых сменах IP.
5. Прислать вам свой домен/IP.

Оговорки Пути Б: нужен публичный IPv4 (не CGNAT — проверить: WAN-адрес роутера = IP на whatismyip). Нет публичного IP → только T2 через cloudflared-туннель (лестница сужается). Плюс: их электричество = ваш аптайм.

### Разделение труда

| Кто | Что |
|---|---|
| Дети | арендуют VPS (или выделяют домашнюю машину) → запускают скрипт → присылают IP |
| Вы | вписываете IP в node.env → правый клик по установщику → готово |
| Коробка | автопереключение, автоперезапуск, автообновление маршрутов, DDNS — вечно, без вас |

## ШАГ 1 — Сервер (5 минут)

Перенеси на VPS ровно два файла: `install-server.sh` и `server.env` (одна папка), затем:

```bash
sudo bash install-server.sh
```

Скрипт сам: скачает последний sing-box, сгенерирует сертификат, запишет конфиг со ВСЕМИ транспортами,
проверит его, включит BBR, зарегистрирует systemd-службу с автоперезапуском, откроет порты в ufw.
Повторный запуск = обновление конфига (идемпотентно).

Порты, которые должны быть открыты у хостера: **443/tcp, 8443/tcp, 443/udp**.

## ШАГ 2 — Windows (5 минут)

1. Впиши `VPS_IP` в `node.env` (больше ничего).
2. Правый клик по `install-sovereign-node.ps1` → **Выполнить с PowerShell от имени администратора**.

Скрипт сам: поставит sing-box в `C:\Program Files\sovereign-node`, отрендерит конфиг из node.env,
проверит его, создаст службу **SovereignNode** (автостарт + автоперезапуск при падении),
включит TUN-режим и стартует.

Проверка: открой https://ifconfig.me — должен показаться IP твоего VPS.
Уже работает: **T1 Reality + T3 Hysteria2** (домен не нужен).

## ШАГ 3 — КРАЙ (опционально, включает T2 через Cloudflare)

Домен — единственное, что нельзя сгенерировать за тебя. Два пути:
- **Платный (1 минута):** любой регистратор, дешёвая зона (.xyz/.top/.icu ≈ $1–3/год). Избегай RU-зон (.ru/.su) — юрисдикция.
- **Бесплатный:** DigitalPlat (dpdns.org / us.kg) через GitHub-аккаунт.

Получил домен → :
1. Впиши его в `node.env` → `DOMAIN=` (и в `server.env`, перезапусти `install-server.sh` на VPS)
2. Запусти `provision-edge.ps1` — он создаст зону в твоём аккаунте Cloudflare, выставит SSL Full,
   создаст DNS-записи (@ → VPS через CDN, direct → VPS напрямую)
3. Выстави показанные nameserver'ы у регистратора
4. Перезапусти `install-sovereign-node.ps1` — он увидит DOMAIN и включит **T2 XHTTP через Cloudflare**

## Что происходит «И САМО» (контракты, которые уже прописаны)

| Событие | Реакция без твоего участия |
|---|---|
| ТСПУ начал рвать TLS к твоему IP | urltest каждые 3 мин переводит трафик на живой транспорт (T2 через CDN или T3 по UDP) |
| Умер весь UDP (T3) | Живёт T1/T2; при восстановлении — автоматически вернётся на лучший |
| Заблокировали IP твоего VPS | T2 продолжает работать через Cloudflare (IP CF не блокируются — за ними пол-интернета) |
| Упал процесс sing-box | Служба Windows перезапустит его через 5/30/60 сек (SCM failure actions) |
| Перезагрузка Windows | Служба стартует автоматически до логина |
| Изменился список RU-сетей | rule-set'ы geosite/geoip-ru обновляются каждые 24 ч |
| Лестница полностью мертва | RU-интернет продолжает работать напрямую (деградация, а не паралич) |

**Лестница:**
- **T1 VLESS+Reality** :443/tcp — TLS-отпечаток Chrome, рукопожатие маскируется под www.microsoft.com. Для ТСПУ это обычный HTTPS-сессия к «микрософту».
- **T2 VLESS+XHTTP** :8443/tcp — обычный HTTP/2-трафик к Cloudflare. Цензор видит соединение с CDN Cloudflare, блокировать которое = отключить интернет.
- **T3 Hysteria2** :443/udp — QUIC с обфускацией salamander (UDP выглядит как случайный шум) + masquerade.
- Транспорт независимы по протоколу (TLS-TCP / HTTP-CDN / QUIC-UDP) и по пути (прямой / через CDN).

## Диагностика (если что-то не так)

```powershell
Get-Service SovereignNode                          # жива ли служба
Get-Content C:\ProgramData\sovereign-node\singbox.log -Tail 50
& "C:\Program Files\sovereign-node\bin\sing-box.exe" check -c C:\ProgramData\sovereign-node\config.json
curl ifconfig.me                                    # чей сейчас выход
```

Частые случаи:
- **Служба не стартует** → смотри log; чаще всего: VPS_IP с опечаткой (проверь node.env → перезапусти установщик)
- **Интернет пропал полностью** → `Stop-Service SovereignNode` вернёт прямой доступ; разбирайся с логом
- **RU-сайт лезет через туннель** → он не в geosite-ru; подожди обновления (24 ч) или добавь домен в правило
- **Проверка IP показывает VPS, но сайт X не открывается** → это сайт блокирует VPS-IP (Netflix и т.п.); T2 через CF решает частично

## Гигиена мандата

1. **Куки сессии Cloudflare, что ты мне дал, — ротируй**: dash.cloudflare.com → иконка профиля → My Profile → Sessions → Log all out (после того как всё настроишь). Куки были в открытом чате — сессия должна умереть.
2. API-токен (он в node.env) остаётся рабочим — это штатный механизм, права только на DNS/зоны/настройки. Удалить/перевыпустить: My Profile → API Tokens.
3. Включи 2FA на аккаунте Cloudflare и на панели хостера. Сейчас её нет — это дыра.
4. `keys.txt` + `server.env` (приватный ключ!) — не держи в папке загрузок; перенеси в KeePassXC.

## Фаза 2 (когда захочешь — коробка расширяема, но сейчас она полная)

- **AWG (AmneziaWG)** — 4-й транспорт: сервис amneziawg на том же VPS + клиент AmneziaVPN (отдельное приложение — сознательно вынесено, чтобы не ломать «один бинарь»)

- **Второй VPS в другой юрисдикции** — второй T1/T3, лестница станет ещё толще
