# Антицензор — СУВЕРЕННЫЙ УЗЕЛ (Chrome/Edge, Manifest V3)

Браузерная версия PAC «Антицензор» из коробки cell65-host: **заблокированные
домены — через твой узел, остальное — напрямую**. Список **129 103 доменов**
(реестр РФ, сборка в шапке файла) **встроен в расширение** — ничего не качает,
работает мгновенно после установки. Тумблер в один клик, режимы переключаются
без перезагрузки браузера.

## Установка (2 минуты)

1. Скачай папку `chrome-ext/` (или zip) на машину.
2. Chrome → в адресной строке набери `chrome://extensions` → включи
   **«Режим разработчика»** (переключатель справа сверху).
3. Нажми **«Загрузить распакованное расширение»** → выбери папку `chrome-ext/`.
4. Закрепи иконку (значок пазла на панели → булавка). Щёлкни по ней — увидишь статус.

Edge: то же самое, но `edge://extensions`.

## Настройка (один шаг)

Правый клик по иконке → **«Параметры»**:

- **Свой узел (рекомендуется)** — впиши IP своего VPS и порт `3128`
  (PAC-эндпоинт поднимает `sovereign-node/server/enable-pac-endpoint.sh` на VPS;
  пароль он генерирует сам и прячет в `server.env`). Нажми «Сохранить и применить».
  При первом заходе на заблокированный сайт браузер один раз спросит логин/пароль.
- **Публичный PAC «АнтиЗапрет»** — работает сразу, без VPS. Трафик заблокированных
  сайтов идёт через чужой сервис (работает только с российских IP).
- **Выключено** — прямой доступ, ничего не перенаправляется.

Пока адрес узла не вписан, расширение в режиме «свой узел» **нейтрально**: ничего
не перенаправляет, на иконке жёлтый знак «?». Ничего не ломается.

## Проверка

1. `2ip.ru` — должен показывать **твой домашний IP** (PAC гоняет только заблокированное).
2. Заблокированный сайт — должен открыться.
3. `bash.ws/dnsleak` — для проксируемых сайтов резолвер будет «проксийный»,
   для остальных — твой провайдер (так задумано).

## Границы (честно)

- Действует **только в этом браузере**. Если на машине уже работает sing-box
  (TUN) — расширение не нужно: TUN ведёт весь трафик.
- Список доменов встроен и обновляется вместе с расширением; свежую сборку для
  системного PAC делает `sovereign-node/pac/build-anticensor-pac.py`.
- Manifest V3: без eval, без удалённого кода; встроенный PAC передаётся сетевому
  стеку Chrome как данные, публичный — как URL (как системный PAC).
- Расширение не шифрует трафик само — шифрование даёт твой узел/https.
