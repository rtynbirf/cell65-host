Настройка маршрутизации: заблокированные домены — через прокси, остальное — напрямую. Список: 129 103 домена (реестр РФ), встроен в расширение.
ПРИМЕНЕНО ✓

Проверка

1. 2ip.ru — должен показывать твой домашний IP (PAC не гоняет всё через прокси).
2. Заблокированный сайт — должен открыться; при первом заходе браузер спросит логин/пароль узла.
3. bash.ws/dnsleak — для проксируемых сайтов резолвер будет «проксийный», для остальных — твой провайдер (так задумано).
4. Расширение действует только в этом браузере. Если на машине уже работает sing-box (TUN), расширение не нужно — TUN ведёт весь трафик.

Пересборка списка (когда реестр обновится)

Список встроен и обновляется вместе с расширением. Свежий PAC для системных настроек Windows собирает sovereign-node/pac/build-anticensor-pac.py (см. README-PAC.md в репе). Для браузера достаточно заменить pac/anticensor.pac в папке расширения и нажать «Обновить» на chrome://extensions.
