Метафора: 64 клетки в сумме дают целое поле - и поле тоже клетка
(65-я). Каждый файл решает свою задачу, каждая клетка внутри
файла - свой шаг. Диспетчер при запуске определяет, где его
разбудили (среда), собирает факты, выбирает конфигурацию, идёт
на давние открытые источники GitHub, набирает списки серверов,
меряет и подключает локальный прокси к ближайшему вне РФ.

ПРО ВСТРОЕННЫЙ VPN (Windows 11 26H1 и новее):
 Да - VPN-механизм является частью самой системы: службы RasMan и
 SstpSvc, rasdial.exe, командлеты Add-VpnConnection, узел
 "Параметры -> Сеть и Интернет -> VPN" (есть и в Home). CELL-65
 использует именно системный механизм - сторонние VPN-клиенты не
 ставятся. Но важно понимать факт: бесплатная VPN-учётка не берётся
 из публичных списков прокси - у тех серверов нет VPN-протокола.
 Поэтому VPN-путь (ряд f) - это ТВОЙ сервер: провайдерский, роутер
 с SSTP/IPsec, любой купленный. Заполнил data\vpn.json -> f2 -> f3.

ЧЕСТНЫЕ ГАРАНТИИ:
 - Списки публичные и бесплатные: часть серверов живёт минуты. Поэтому
   отбор - по замерам (TCP мс + живой HTTP-204), и h4 умеет менять
   upstream без твоего участия.
 - Ноль удалений: CELL-65 ничего не стирает; свои артефакты снимает
   только через undo (h2, f6), твои данные и журналы остаются.
 - Ноль вердиктов: журнал пишет факты и координаты (коды, порты,
   время замера). Решение - всегда твоё.
