CELL-65 Поле 8x8 :: Chrome (Manifest V3) - установка и режимы
==============================================================

НОВОЕ В v5 (факт с машины пользователя)
- В v4 клетки b1/b3/b5/d2/g1/g4 давали x: браузер валил ЧТЕНИЕ настроек
  прокси (settings.get в promise-форме), при том что ЗАПИСЬ работала.
- В v5 чтение идёт в 4 формах (promise/callback, со scope и без) и клетку
  не валит: если браузер так и не отдал настройки - в журнале появляется
  точный текст ошибки и клетка продолжает замер в текущем режиме.
- Если b5/g4 показывают "не читаются" - пришли хвост журнала: в нём теперь
  сам текст ошибки браузера (факт, не вердикт).

ЧТО ЭТО
- Плагин = зеркало скрипта CELL-65 внутри Chrome: та же доска 8x8 = 64 клетки,
  те же координаты a1..h8, что в cells\c01..c08.
- Два режима, как в скрипте:
  1) ПОЛУАВТОМАТ - настройка и диагностика по клеткам: клик по клетке (a1..h8)
     или по ряду (a СРЕДА, b СЕТЬ, c СПИСКИ, d ПРОБА, e ЛОКАЛЬ, f VPN, g ПРОКСИ,
     h ЖИЗНЬ) - факт появляется в журнале, клетка окрашивается (o ок / x сбой).
  2) АВТОМАТ - одна кнопка АВТО-ЦИКЛ (списки -> проба -> выбор, как 65.cmd auto)
     + СТОРОЖ: каждые 30 мин проверяет здоровье, при сбое сам включает
     следующий сервер по кольцу СПБ (зеркало клеток e7/h4 скрипта).
- Порядок списка серверов задаёт клетка d6: вне домена РФ, кольцо дистанции
  от СПБ (59.9386, 30.3141), затем скорость (живой замер 204).
- Прокси включается ТОЛЬКО в Chrome (chrome.proxy). Системные настройки
  Windows расширение не трогает; системный путь - это ряд g скрипта (gost).

УСТАНОВКА (1 раз)
1) Chrome -> адресная строка: chrome://extensions
2) Справа сверху включить "Режим разработчика".
3) "Загрузить распакованное расширение" -> выбрать папку chrome-mv3
   (ту, где лежит этот файл и manifest.json).
4) Значок "CELL-65 Поле 8x8" закрепить на панели (pin).

ПОЛУАВТОМАТ (настройка + диагностика) - вкладка "ПОЛУАВТОМАТ"
- Сверху кнопки рядов a..h: клик = весь ряд (8 клеток подряд).
- Доска 8x8: клик по клетке = одна клетка. Подсказка каждой клетки - в
  всплывающем тексте (title). Состояние: . / > / o / x.
- Журнал внизу: факты с метками времени. Он же хранится в storage.
- Порядок первой настройки (как в скрипте: c -> d -> g2):
  c1..c8  - списки серверов с GitHub (те же 9 источников, что в скрипте);
  d1..d8  - проба: выборка -> живой замер 204 через Chrome (прокси
            переключается по одному кандидату и восстанавливается сам) ->
            гео выживших -> отсечение РФ -> ВЫБОР (вне РФ, кольцо СПБ);
  g2      - включить выбранный сервер (или клик по строке во вкладке СЕРВЕРЫ).
- Диагностика: a1..a8/b1..b8 - среда и сеть; e4/e7 - здоровье и смена
  upstream; f7 - факты о VPN; g4/g5/g7 - состояние прокси.

АВТОМАТ - вкладка "АВТОМАТ"
- [АВТО-ЦИКЛ] = ряд c + ряд d (полный цикл, как 65.cmd auto).
- Галка "применять выбор сразу (g2)": авто-цикл сам включит лучший сервер.
- [СТОРОЖ]: вкл/выкл. Пока Chrome запущен, каждые 30 мин проверка здоровья;
  при сбое - следующий сервер по кольцу. Состояние сторожа - в журнале.
- [ОТЧЁТ (h6)] - полный текст отчёта в буфер обмена (доска + факты + журнал).
- [UNDO (h2)] - прокси direct, сторож выкл. Данные не трогаются (ноль удалений).

СЕРВЕРЫ (ручное переключение)
- Список уже отсортирован как d6: ранг, кольцо R1..R5/R?, страна/город, км, время.
- Клик по строке = включить этот сервер. Активная строка подсвечена.
- DIRECT (выкл) = напрямую, без прокси.
- Импорт: файл CELL65\data\servers_export.json (клетка d6 скрипта) - файлом
  или вставкой текста. После каждого нового d6 - повтори импорт.
- На значке бейдж = активное кольцо (R1..R5, R?).

ЧТО ЖИВЁТ ТОЛЬКО В СКРИПТЕ (факт архитектуры браузера)
- Системный прокси Windows (HKCU) и gost 127.0.0.1:18080/18081 - ряд e/g скрипта;
  плагин видит только факт "gost отвечает" (клетка b6).
- VPN (RasMan, rasdial, профили) - ряд f скрипта; плагин даёт факты/координаты
  (f1..f8) и шаблон vpn.json (f8, попадает в отчёт h6).
- winhttp - клетка g6 скрипта.
- В браузере нет планировщика задач: автоустановка при входе = задача CELL65
  скрипта (h1); в плагине ту же роль несёт СТОРОЖ (пока Chrome запущен).

ФАКТЫ
- socks4/socks5/http переключаются автоматически по полю proto.
- localhost (<local>) всегда идёт напрямую, не через прокси.
- Во время пробы (d2/d3/d4) прокси Chrome ненадолго переключается на
  кандидатов - после пробы восстанавливается прежняя настройка (факт в журнале).
- Расширение ничего не удаляет и не меняет в системе: только свой профиль
  Chrome и своё хранилище (chrome.storage.local).
- Нет удалённого кода: все скрипты внутри папки (Manifest V3, service worker).

ИЗМЕНЕНИЯ 2.2.0 (ext)
- 407 без окна: если прокси требует логин/пароль, запрос гасится автоматически -
  диалог «Для доступа на прокси-сервер требуется имя пользователя и пароль»
  больше не появляется (ни во время пробы, ни после неё).
- строгая проверка host:port перед применением (пул, импорт СЕРВЕРЫ, ручной выбор):
  кривые адреса вида 193.8215.32:6443 отбраковываются до chrome.proxy.settings.set.
- подсказка в статусе (h7): окно авторизации при выключенном прокси = системный
  прокси Windows (Параметры - Сеть и Интернет - Прокси); плагин его не трогает.

ИЗМЕНЕНИЯ 2.5.0 (ext):
- ЖИЗНЬ больше не ретраит проваливших пробу (живая жалоба 6ORMAN "второй раз
  подключается к тому, что не работало"): карантин 30 минут на узла с потерянным
  здоровьем (зеркало PS cooldown.tsv) + 407-узлы пробы исключаются из запасных
  всегда; когда все в карантине - полный список минус активный (лучше попытка,
  чем простой).
- Чистка Cloudflare-мусора: официальные 15 IPv4-сетей Cloudflare
  (cloudflare.com/ips-v4) отсекаются трижды - при разборе источника, при сборке
  пула (защита от старых пулов в хранилище) и в выборке пробы. Зеркало в PS:
  Test-CfIp (lib65.psm1) + фильтр в c3 (сборка pool.tsv).

ИЗМЕНЕНИЯ 2.4.0 (ext):
- Проба d2 разделила мёртвых: узлы с 407 (требуют авторизацию) уходят в список
  auth407 и больше не тратят время проб; выборка d1 их исключает. Итог пробы:
  "живые N | 407: M | мертвы/полумертвы: K".
- Вердикт "живой" усилен: 204 + реальный трафик (msftconnecttest по HTTPS).
  Полумёртвые (204 есть, интернета нет) в живые не попадают - это и было
  "подключились к серверу без доступа в интернет".
- Сторож h4: та же двойная проверка перед вердиктом и сменой upstream.
- Гео и фильтр выбора: от ДОМА (авто, b1), а не от СПБ - универсально из любой страны.
- h7: подсказка про мост Chrome<->локаль (127.0.0.1:18080) при direct.

ИЗМЕНЕНИЯ 2.3.0 (ext)
- Меритократия: живой сервер копит очки (+10 за пробу), сбой = x0.3 - сторож
  переключает на следующий ПО ОЧКАМ (лидер-на-час), старение x0.9 за авто-цикл.
- Список серверов и статус показывают очки (sc50 и т.п.).
- clarketm исключён из источников (6 мес без обновлений); roosterkid +socks4.
